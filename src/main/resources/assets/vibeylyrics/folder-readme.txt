Vibey Lyrics - song folder / Song-Ordner
=========================================

EN
Put your music here. A song is an audio file and an .lrc file with the same name:

    Artist - Title.ogg
    Artist - Title.lrc

Audio: .ogg, .mp3 or .wav. Lyrics: .lrc with time tags like [01:23.45]. Word tags
(<01:23.45>word) give word-by-word karaoke; without them the words are timed by length.
A song with only an .lrc file runs on a timer: start the music yourself (Spotify, a
speaker, ...) at the same moment and line it up with the -0.5s / +0.5s buttons.
No lyrics? Use "Find lyrics online" in the menu (LRCLIB, lrclib.net).
Open the menu with K or "♪ Lyrics" in the pause menu.

DE
Leg deine Musik hier ab. Ein Song ist eine Audiodatei und eine .lrc-Datei mit dem
gleichen Namen:

    Künstler - Titel.ogg
    Künstler - Titel.lrc

Audio: .ogg, .mp3 oder .wav. Lyrics: .lrc mit Zeitstempeln wie [01:23.45]. Wort-Stempel
(<01:23.45>Wort) ergeben Karaoke Wort für Wort; ohne sie wird nach Länge verteilt.
Ein Song nur mit .lrc läuft mit Timer: Starte die Musik selbst (Spotify, Lautsprecher,
...) im selben Moment und richte sie mit -0,5s / +0,5s aus.
Keine Lyrics? Im Menü "Lyrics online suchen" (LRCLIB, lrclib.net).
Menü mit K öffnen oder über "♪ Lyrics" im Pausemenü.
